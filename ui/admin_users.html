Known devices

While Remote Access is on, Clear Units removes only the units that no user, display group or saved video wall uses; assigned units are kept. With Remote Access off, it clears every unit and removes it from every account’s sources and displays, from display groups and from this list of names. Scan again to find units that were cleared.

Display groups

A group is a named set of displays that all receive the same source, one after another. It has no layout: each display shows the whole picture. Granting a group to a user does not give them the individual displays in it.
