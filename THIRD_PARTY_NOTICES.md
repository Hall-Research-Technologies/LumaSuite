The CPython runtime also carries the libraries it was built with (OpenSSL, libffi, zlib, bzip2,
lzma, expat and the Microsoft Visual C++ runtime on Windows). Their licence texts are those that
ship with the CPython build and are not separately reproduced here, apart from the Apache-2.0 text
that `cryptography` carries (OpenSSL is distributed under Apache-2.0). The Python runtime uses
OpenSSL 3.5.9; the `cryptography` extension carries its own build of OpenSSL.

## Things to know

- **pystray 0.19.5 is licensed under the GNU Lesser General Public License, version 3.** LumaSuite uses it
  unmodified for the system-tray icon, and the LumaSuite executable is a combined work with it. pystray and its use
  are covered by the LGPL; the GNU GPL v3 and the LGPL v3 texts are in `licenses/pystray/COPYING` and
  `licenses/pystray/COPYING.LGPL`. Copyright (C) Moses Palmer.

  **Source.** The exact corresponding source is included, not just linked: `third_party/pystray-0.19.5/` (the upstream
  source archive for tag v0.19.5, the PyPI wheel the build installs, an extracted `source/` copy and `PROVENANCE.md`
  with sizes and SHA-256 hashes). It sits beside `LumaSuite.exe` in the release package and in the LumaSuite repository.
  Upstream: https://github.com/moses-palmer/pystray and https://pypi.org/project/pystray/0.19.5/.

  **Replacing pystray.** `LICENSE` section 11A lets you modify pystray and rebuild LumaSuite against your modified copy
  for your own use. pystray is compiled into the single-file executable, so this is done by rebuilding: obtain the
  LumaSuite source for this release, install your modified pystray over the pinned 0.19.5 in the build environment,
  and run `build_executable.py`. The exact steps are in `REBUILD.md`, which also ships beside the executable.
- **setuptools lists a second LGPL-3.0 library, `autocommand`**, among the libraries it vendors. setuptools
  is in the executable only because PyInstaller's runtime hooks pull it in; LumaSuite's own code does not import
  it. In the Windows executable inspected for this file, setuptools' vendored libraries (including `autocommand`)
  are not present as code; only their licence texts are. The text is kept so the list stays complete; no `autocommand` code is distributed in the executable.
- **macOS and Linux builds** add platform packages resolved at build time (for example
  `python-xlib` on Linux and the `pyobjc` Quartz binding on macOS). Those builds have not been
  inspected for this file; their texts are not collected here. Treat the list above as the
  Windows x86-64 package until those archives are inspected.
- Pillow's licence file also lists the licences of the image libraries it bundles.
- certifi's licence file is the Mozilla Public License 2.0 notice that certifi ships, not the full licence
  text. certifi is used unmodified; its source is the published `certifi` release on PyPI.
